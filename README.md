# e-plantShopping

En frontend-applikasjon for kjøp av planter i en simulert netthandelsløsning. Prosjektet ble utviklet som del av et IBM-kurs i React med tilhørende eksamen, og fungerte som et læringsprosjekt med fokus på moderne webteknologier, komponentbasert utvikling og praktisk bruk av React og Redux.

## Teknologier

### Frontend
- React (EcmaScript6)
- Redux (tilstandshåndtering)
- React Router (navigasjon)
- Axios (API-kall)

### Annet
- Vite

---

## Funksjonalitet

- Bla gjennom produkter (planter) i oversiktlig listevisning
- Legg til/fjern varer fra handlekurv
- Simulert utsjekk og bekreftelsesside
- State management med Redux og globale action
